# 🏦 Banking Console Application

## 📌 Overview

The **Banking Console Application** is a simple Python-based command-line project that simulates basic banking operations. It allows users to create and manage bank accounts through an interactive menu-driven interface. The project is designed using a modular architecture, making the code easy to understand, maintain, and extend.

The application stores account information in memory using a **Python dictionary**, where each account is represented as a **dataclass** object. Users can perform essential banking operations such as creating an account, depositing funds, withdrawing money, checking account balance, viewing all accounts, and closing an account.

This project demonstrates the use of Python fundamentals, including dataclasses, dictionaries, functions, loops, conditional statements, and modular programming. It is intended as a beginner-friendly console application for learning basic data structures and object-oriented programming concepts.

---

## ✨ Features

* Create a new bank account
* Deposit money into an account
* Withdraw money from an account
* Check account balance
* View all customer accounts
* Close an existing account
* Prevent duplicate account IDs
* Validate invalid deposit and withdrawal amounts
* Handle non-existent account operations gracefully
* Menu-driven console interface
